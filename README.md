1. システム概要と基本仕様
1.1 アプリケーションの概要と目的
システムの目的と全体像「KyoteiYoso」は、全国24ボートレース場（唐津、福岡、下関、徳山、児島、丸亀、鳴門、住之江、びわこ、津、浜名湖等）のオフィシャルデータである番組表テキストファイル（B261012.TXT）およびレース結果ファイル（K261012.TXT等）を解析し、客観的・定量的な勝率アルゴリズムに基づいて買い目を自動算出する競艇データアナリティクス・予想実行システムです。
固定長テキストの構造化データ処理システムは入力された B261012.TXT 内の固定長テキスト行に対して正規表現（Regex）によるパターンマッチングを実行します。ヘッダー情報（競艇場コード、開催日、日次、レース番号、レース名、電話投票締切時刻等）とボディ情報（1〜6号艇の選手登番、氏名、年齢、支部、体重、級別、全国/当地スタッツ、モーター/ボート2連率、今節成績文字列）を抽出し、データ型変換および事前バリデーションを行った上でリレーショナルデータベースへと構造化保存します。
多角的な予想エンジンと買い目算出の自動化データベース化された選手実績（勝率・2連率）および機材スタッツを「キャッスルV6」や「新・スコア予想」などの専用予想エンジンに供給します。レースごとに展開（イン逃げ、マクリ、サシ等）をシミュレーションし、競艇場特有のローカルルールや番組編成者の意図（クセ）を加味した自動スジ買い生成、および資金分配計算までを一貫して自動化します。

2. システム起動手順と基本操作
2.1 アプリケーションの起動と初期設定
環境変数のロードとデータベース接続確認ターミナルを開き、環境変数 DB_CONNECTION_STRING および KYOTEI_ENV=production が正常に設定されているか確認します。
export DB_CONNECTION_STRING=”Server=localhost;Database=KyoteiDb;User=kyotei_app;Password=secret;”

KyoteiYoso CLI/システムの初期化設定初期化コマンドを実行し、設定ファイル（config.json）の整合性とデータベースのスキーマ状態を検証します。
kyoteiyoso-cli init --config config.json

競艇場別ローカルルールのセットアップ各開催場（唐津、福岡、下関等）の特性補正テーブルおよびイン加点・減点パラメータをシステムメモリに展開します。
インポート対象ファイルのバッチ指定と起動取り込み対象となる番組表テキスト（B261012.TXT）および結果テキスト（K261012.TXT）の格納パスを指定してメインアプリケーションを起動します。
kyoteiyoso-cli run --input-dir=/data/import/20261012 --date=20261012

2.2 データスクレイピングおよびファイルインポート処理
ステップ1：外部テキストファイルのロードとエンコーディング変換指定フォルダに配置された B261012.TXT（Shift-JIS/CP932）を読み込み、内部処理用UTF-8バッファへストリーミング変換します。
ステップ2：レースヘッダー情報の正規表現パースSTARTB 〜 23BEND などの競艇場ブロックタグを検知し、場コード、レース番号（１Ｒ〜１２Ｒ）、電話投票締切時刻（電話投票締切予定０８：４３ 等）、企画レース名（朝１戦, 釜揚げ８ 等）を抽出します。
ステップ3：艇別（1〜6号艇）レコードの解析と数値化固定桁レイアウトに従い、艇番・登番・氏名・級別（A1〜B2）・全国勝率・当地勝率・モーター2連率・ボート2連率をパースして float/int 型にバインドします。
ステップ4：特殊記号コードのパース処理と例外キャッチ今節成績文字列内に含まれる特殊フラグ記号（F＝フライング［例: 335F4］、K＝欠場・事故［例: 11K 4436］、S＝完走/スタート展示コード［例: S21］）を正規表現で検知します。数値変換時に FormatException を発生させないよう特殊記号をエスケープ分離し、不祥事故フラグとして別フィールドにバインドします。当地実績が存在せず 0.00 と記録されている場合（例: 福岡1R 1号艇・北中元樹の当地勝率0.00）は、NULL 扱いとせず初期値 0.00 を維持し、計算用の代替デフォルトロジックを通します。
ステップ5：解析データベースへのアトミック書き込みトランザクションを開始し、抽出したレースデータおよび選手スタッツを races テーブルおよび race_entries テーブルへ一括インサート/更新（Upsert）処理します。
3. 各種予想ロジックの解説と運用方法
3.1 キャッスルV6ロジック
「キャッスルV6」は、選手の実力スタッツ（全国・当地勝率）と機材性能（モーター・ボート2連率）を多角的に加重補正する主力予想エンジンです。

加重評価軸と補正計算
基本実力軸 ：全国勝率（ウェイト 40%）＋ 当地勝率（ウェイト 30%）
機材性能軸 ：モーター2連率（ウェイト 20%）＋ ボート2連率（ウェイト 10%）
判定基準と実データ適用例
ケース1［唐津1R 1号艇・白水勝也（登番3576, A1級）］
スタッツ : 全国勝率 6.08 / 当地勝率 6.42 / モーター2連率 0.00% / ボート2連率 33.86%
評価プロセス : 全国勝率（6.08）に対し当地勝率（6.42）が高いため「当地適性加点（+0.34pt相当）」が適用されます。一方でモーター2連率が 0.00%（NO.28）と極端に低いため、「機材超低速減点（-1.50pt）」が発動します。1号艇A1級の基本評価をベースにしつつも機材不安による波乱含みと判定されます。
ケース2［津12R 5号艇・峰竜太（登番4320, A1級）］
スタッツ : 全国勝率 8.84 / 当地勝率 7.44 / モーター2連率 29.41% / ボート2連率 30.99%
評価プロセス : 全国勝率 8.84 という圧倒的な実力値を誇り、5号艇（外枠）配置であっても「絶対能力評価点（+3.50pt）」が加算されます。枠番による不利を覆して2着以内・頭狙い（5-1, 1-5等）へ自動拡張される評価を下します。

3.3 格言集スジ買いシステム
競艇の展開セオリー（「格言」）をアルゴリズム化し、レース展開に応じた買い目スジ（出目パターン）を自動生成します。

「イン強し、軸揺るがず」（1号艇逃げスジ）
発動閾値条件 : 1号艇が A1級 かつ 全国勝率 6.00 以上 （または当地勝率 6.50 以上）。
生成出目 : 1-2-3, 1-2-4, 1-3-2, 1-3-4, 1-4-2（本線5点）。1頭固定で2・3着に軸選手を配置。
「2角の差し、3角のマクリ」（2・3号艇展開逆転スジ）
発動閾値条件 : 1号艇のスコアが低く、2号艇または3号艇が A1級 かつ モーター2連率 35% 以上 。
生成出目 : 2号艇差し展開＝ 2-1-3, 2-1-4, 2-3-1 / 3号艇マクリ展開＝ 3-1-2, 3-1-4, 3-2-1（穴スジ自動生成）。
「外枠の好機、流しで拾え」（波乱流しスジ）
発動閾値条件 : 5号艇または6号艇の 当地勝率が 7.00 以上 または モーター2連率 40% 以上 。
生成出目 : 1-5-全, 1-6-全, 5-1-全（外枠追走・突き抜けスジ）。

4. パラメータ調整機能の使い方と設定効果
4.1 展示加点パラメータの設定と効果
データ取得タイミングレース直前（締切15分前）にスクレイピングされる「直前展示情報」から、スタート展示のF/L情報、平均ST、および周り足展示タイムを取得します。
本線スコア算定式$\text{最終スコア} = \text{基本予想スコア} + (\text{展示評価ポイント} \times \text{展示加点パラメータ})$
パラメータ設定値と効果
スタート展示評価パラメータ（設定範囲: 0.0 〜 +2.0） : 0.15秒以内の好スタートを切った選手に +1.5pt を乗算加点。
周り足展示評価パラメータ（設定範囲: 0.0 〜 +1.5） : ターン回りタイムが節内上位10%以内の選手に対し +1.0pt を乗算加点。
4.2 イン飛び減点パラメータの設定と効果
1号艇（インコース）の敗退（イン飛び）リスクを判定し、1号艇のスコアを減算補正するテーブルです。

適用条件	減点数値	実在ソース適用例（B261012.TXT）
1号艇が B1/B2級 かつ 全国勝率 4.00 未満	-2.5 pt	唐津4R 1号艇・中嶋達也（B1級 / 全国勝率 3.92 / 当地 3.38）
1号艇のモーター2連率が 20.00% 未満	-2.0 pt	唐津1R 1号艇・白水勝也（A1級 / モーター2連率 0.00%）
1号艇の当地勝率が 0.00（当地実績なし）	-1.5 pt	福岡1R 1号艇・北中元樹（A1級 / 当地勝率 0.00）
4.3 隠れA級検知・補正機能
B1級またはB2級の表記でありながら、実質的にA級相当の能力を持つ「隠れA級」選手を自動検知し、スコアを上方修正します。

検知フラグ発動条件
条件A : 級別が B1/B2 でありながら、 全国勝率 5.50 以上 または 当地勝率 6.00 以上 。
条件B : 今節成績において1着・2着を複数回獲得。
実在ソース（ B261012.TXT ）からの検知実例と補正
実例1［住之江3R 5号艇・西島義則］ : 表記は B2級 であるが、全国勝率 7.20 ・当地勝率 7.16 （2連率70.00%）。「隠れA1級」フラグが自動付与され、基本スコアに +15.0pt （A1級と同等補正）を自動加算。
実例2［丸亀3R 5号艇・谷川祐一］ : 表記は B1級 であるが、全国勝率 6.31 ・当地勝率 5.64 。「隠れA2級」フラグが付与され、スコアに +10.0pt を自動加算。
実例3［下関1R 5号艇・澁川夏］ : 表記は B1級 であるが、全国勝率 5.77 。「隠れA2級」フラグが付与され、スコアに +8.0pt を加算。
4.4 外枠拡張パラメータの設定と効果
外枠（5・6号艇）のハイスペック条件照合5・6号艇に配置された選手が「A1/A2級」かつ「当地勝率 7.00 以上」または「モーター2連率 40% 以上」を満たすか判定します。
該当例1［徳山3R 5号艇・上條嘉嗣］ : A1級 / 全国勝率 6.88 / 当地勝率 7.81
該当例2［唐津5R 6号艇・芦澤望］ : A2級 / 当地勝率 7.40 / モーター2連率 45.45%
外枠拡張パラメータ（ OUTER_EXPANSION_WEIGHT ）のON設定拡張パラメータ（範囲: 1.0 〜 1.5）を 1.3 に設定し、該当艇のスコア底上げを実施。
流し買い・穴買いスジ（5-1, 6-1等）の自動生成本線 1-5, 1-6 に加え、逆転頭買いスジ 5-1-全, 6-1-全 を買い目リストへ自動挿入・拡張します。
5. 資金配分およびスマートキャッシュ機能
5.1 傾斜資金分配計算機能
オッズおよび予想スコアに基づき、的中時の払戻額が一定以上になるよう投資資金を各買い目へ傾斜配分します。

算定式（標準プレーンテキスト表記）
各買い目購入額 = 総投資額 * ( (該当買い目の予想スコア / 該当オッズ) / Sum(全買い目の予想スコア / 該当オッズ) )

※算出された金額は100円単位（端数切り捨て/四捨五入アルゴリズム）に丸め処理されます。

操作手順
総投資金額の入力 : 対象レースにおける目標投資合計額（例: 10,000円）を入力ステップで指定。
リアルタイムオッズの同期 : 締切5分前の最終オッズAPIデータを取得。
配分計算実行 : 算定式に基づき全買い目の配分額を自動確定し、最小賭け金（100円）未満の低期待値目をカット。
5.2 スマートキャッシュ機能の仕様と運用
キャッシュ機能のメリット同一開催日の番組表データ（B261012.TXT）に対する重複パースや予想エンジンの再計算処理をスキップし、レスポンス速度をミリ秒単位に高速化するとともにDB負荷を低減します。
保持ルールとキー構造
保存先 : ローカル Redis インスタンス（またはインメモリキャッシュ）
キャッシュキー構造 : cache:program:{YYYYMMDD}:{競艇場コード}:{レースNo}（例: cache:program:20261012:23:01）
有効期限（TTL） : 対象レースの電話投票締切時刻から30分後まで自動保持。
管理操作コマンドデータ更新や再取り込み時は、以下のCLIコマンドまたは管理Redisコマンドで手動クリアを実行します。
kyoteiyoso-cli cache clear --date=20261012
# または Redis CLI 直接実行
redis-cli del “cache:program:20261012:*“

6.2 データ整合性確認と運用保守手順
主催者発表公式データの照合 : B261012.TXT（番組表）内の競艇場名、レース番号、電話投票締切時刻が公式発表値と合致していることを確認する。
レースキー相互照合 : B261012.TXT（番組表）と K261012.TXT（結果データ）のレースキー（場コード + 日付 + レースNo）が1対1で整合しているかクロスチェックする。
スタッツ欠損チェック : 全6艇の登番、級別（A1〜B2）、全国・当地勝率、モーター・ボート2連率に不正な空白や文字化けがないか検証する。
不整合発生時の再インポート : データの食い違いを検知した場合、kyoteiyoso-cli cache clear を実行してキャッシュを破壊し、テキストファイルを再ロードする。
システムログの監査 : システムログファイル（/var/log/kyoteiyoso/app.log）を検索し、ERROR や WARNING レベルのパース例外が記録されていないことを確認する。
